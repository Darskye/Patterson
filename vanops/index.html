Shooting it

Every keyboard drives every screen. Hit 1–5 anywhere and the whole wall moves to that story phase together. A presenter clicker works too — its arrow keys step the phase forward and back.

Put one screen per monitor. Open a card, drag the window to the display you want, then press F for fullscreen. Repeat.

The terminal is the hero. Leave it in SCRIPT MODE and let the actor mash the keyboard — the hack types itself, perfectly, every take. \ resets it for the next one.

If the wall stops syncing

Serve the folder over http:// — run serve.sh (or serve.bat) and open localhost:8080. Opening the files straight off disk still looks right, but the browser blocks screen-to-screen cues.
